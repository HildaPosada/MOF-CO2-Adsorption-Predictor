# Learned browser model

`python scripts/train_browser_model.py` trains a scikit-learn MLP regressor on 3,000 synthetic records generated by the existing repository code and exports weights, scaler parameters, input ranges and held-out metrics to `web/model.json`. Browser predictions perform the same scaled dense-layer operations, rather than a hand-written scoring formula.

The 80/20 split uses seed 42. A Ridge regression baseline is evaluated on the identical test rows. The model estimates the generator, not experimentally measured adsorption. The residual band is an empirical synthetic-test statistic, not a calibrated interval for real materials. The selected six input features match the generator target.

NIST experimental isotherm and JARVIS hMOF downloads were investigated; their download endpoints were unavailable during this run. An experimental or published simulation dataset with matched descriptors and pressure/temperature conditions is required before scientific generalization claims.

Sources: https://adsorption.nist.gov/ and https://pages.nist.gov/jarvis/databases/
